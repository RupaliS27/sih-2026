# 0002: Dual-Persona System Boundary

We decided to partition the user experience into two distinct personas—Farmer Field Mode and State Agriculture Official War Room—backed by shared deep domain modules, rather than presenting a single monolithic dashboard to all users.

Smallholder farmers require a mobile-first, high-contrast, camera-first interface in regional vernacular (Marathi/Hindi) providing immediate localized spray recipes, whereas district and state agricultural officers require regional macro-surveillance, taluk-level outbreak heatmaps, and mass advisory broadcast capabilities. Separating the presentation tier while anchoring both to unified underlying pathology, microclimate, and economic modules ensures both operational simplicity in the field and strategic visibility at Krishi Bhavan.
